# AI-Based Personalized Treatment Plan Generator

A Smart Healthcare hackathon prototype that predicts one of 15 diseases from synthetic patient data and displays dataset-based care guidance.

## Run the interface

```bash
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```

Enter age, gender, symptoms, medical history, and current medications to generate a disease prediction with confidence and a treatment-plan guidance section.

## Safety

This educational prototype uses synthetic data. It is not a medical device and must not be used for real diagnosis or treatment decisions. Seek urgent medical care for emergency symptoms.
